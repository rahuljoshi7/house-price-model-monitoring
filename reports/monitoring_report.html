4. Interpretation and Limitations

  • Data drift means input feature distributions have changed.
  • MAE and RMSE measure prediction errors; lower values are better.
  • R² values closer to 1 generally indicate a better fit.
  • A performance warning is raised when current MAE is more than 20% higher than reference test MAE.

This assignment uses synthetic data. Real production performance monitoring requires actual house prices to become available. Performance degradation can indicate concept drift but does not prove it by itself. The model is saved for reuse; this script retrains the baseline model on each run for reproducible assignment evaluation.
